# 界面观察记录（据参考视频逐帧提取）

来源：`ScreenRecording_11-22-2026 20-36-55_1.MP4`（1320×2868，HEVC 10bit HDR，44.7s）
以下为当前实现依据，随新截图与新观察持续补充。

## 首页

- 纯黑背景，中央偏上为蓝色鲸鱼标志 + 「你好，让我们开始聊天吧」，无输入历史时无标题。
- 顶部左侧圆形汉堡按钮；右侧为「声音」与「＋」两枚圆形按钮。
- 输入卡片：圆角约 24pt，暗灰填充，占位文案「发消息或按住说话」。
- 卡片下方左侧两枚胶囊开关「深度思考」「智能搜索」，开启时蓝色文字 + 蓝色低透明度底。
- 卡片右下：文字为空时显示波形（语音）按钮，有文字时切换为蓝色圆形发送按钮。
- 输入区下方为最近图片缩略图横条（右上角圆形删除），再下一行为「拍照 / 相册 / 文件」三个等宽按钮。
- 最底部免责声明：「回答由 AI 生成，仅供参考」。

## 对话

- 用户消息：右对齐灰色气泡，圆角约 20pt；图片与文字同处一个气泡时，图片在上、文字在下。
- 助手消息：无气泡、通栏正文；Markdown 标题、有序/无序列表、加粗均可见。
- 思考框：流式时为「正在思考」+ 向下箭头，文字在固定高度框内自动向下滚动，左侧有 2pt 竖线；
  正文开始后自动收为一行「已思考（用时 19 秒）」，点击可重新展开完整过程。
- 思考框内除思考正文外还有条目行，如「搜索到 27 个网页」「已浏览 5 个页面」。
- 图片理解时标题会变为「正在分析图片」，并非固定「正在思考」。
- 助手消息底部操作行：复制、赞、踩、朗读、分享转发，右下另有回到最新位置按钮。
- 生成中顶部标题为「新对话」，首轮结束后标题自动变为会话主题（视频中为「送东阳马生序习题」）。

## 语音输入（长按说话）

- 按住后输入区整体被一片蓝色辉光覆盖，辉光从底部向上扩散、亮度峰值在输入框下方，
  向上与四周快速衰减，与深色背景形成软过渡。
- 输入框轮廓仍浮在辉光之上，左侧显示本次已选附件缩略图。
- 辉光中央文案「松手发送，上滑取消」，下方为细密点状波形，随音量起伏。
- **光效与手指位置联动**（用户补充）：辉光中心随按住位置与上滑距离变化，上滑进入取消区间时提示与光效同步变化。
  实现时不能做成静态渐变动画，需以触摸位置为驱动的径向渐变 + 亮度衰减。
- 松手后先出识别文字并作为本人消息显示，再按普通文本发出；说话过程中不出实时文字。
